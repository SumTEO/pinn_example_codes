# PINN Example Codes

English | [简体中文](README_zh-CN.md)

[`pinn_code_tutorial.ipynb`](pinn_code_tutorial.ipynb) is a runnable tutorial with three progressively more advanced examples:

- RC circuit: data fitting, physics constraints, and parameter discovery
- Steady-state chip thermal analysis: a two-dimensional Poisson equation with a finite-difference reference solution
- PN junction: electric potential and electric field calculation

## Run

```bash
pip install jupyter torch numpy scipy matplotlib
jupyter notebook pinn_code_tutorial.ipynb
```

Run all cells from top to bottom. The chip and PN-junction examples include L-BFGS refinement, so execution time depends on your hardware.
